# DualTech Diaries — LinkedIn PDF to Resume & Portfolio Generator

> Created & Owned by **Srigayathri Rajkumar**

An interactive, high-performance web application that parses LinkedIn "Save to PDF" profile exports, provides an interactive profile review dashboard, generates multi-theme portfolio websites, and exports ATS-friendly PDF resumes.

## Features

- **Owner**: Srigayathri Rajkumar
- **Client-Side PDF Parsing**: Fast, privacy-preserving PDF extraction using `pdfjs-dist`.
- **Instant Demo Loader**: 1-click sample profile loader for instant testing.
- **Interactive Review & Editor**: Full profile editor for personal info, experience, education, skills, and projects.
- **4 Custom Themes**:
  - Modern Tech (Dark Mode Flex ⚡)
  - Executive Minimalist (Quiet Luxury 🏛️)
  - Creative Studio (Bold & Iconic 🎨)
  - Swiss Grid (Clean Code Energy 💻)
- **ATS Resume Export**: Print-ready and downloadable PDF resume format.
- **JSON Portability**: Import and export profile data in JSON format.

## Getting Started

1. Navigate to `portfolio_generator/`:
   ```bash
   cd portfolio_generator
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000` in your browser.
